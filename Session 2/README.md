# Session 2 — MTConnect Adapters and Agents

This folder contains materials and resources for **Session 2: MTConnect Adapters and Agents** from the MTConnect Education Bootcamp 2025.

---

## 📌 Session Description

This session provides a deeper dive into the **core architecture of MTConnect**, focusing on the roles and interaction of adapters and agents.

Topics covered include:

* The purpose and function of MTConnect Adapters
* The role of the MTConnect Agent
* How data flows from devices to applications
* Communication patterns and protocols

This session builds directly on the foundational concepts introduced in Session 1.

---

## 🎯 Learning Objectives

By the end of this session, participants should be able to:

* Explain the responsibilities of adapters and agents
* Describe how machine data is collected and exposed
* Understand the data pipeline from device to client
* Identify how to configure or implement basic adapters and agents
