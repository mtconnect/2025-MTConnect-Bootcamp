# Session 3 — MTConnect Device Files and Data Items

This folder contains materials and resources for **Session 3: MTConnect Device Files and Data Items** from the MTConnect Education Bootcamp 2025.

---

## 📌 Session Description

This session explores how MTConnect represents machines and their data through **Device Configuration Files** and **DataItems**.

Topics covered include:

* Structure and purpose of MTConnect Device files
* Definition and organization of DataItems
* How device models describe real-world equipment
* Mapping machine signals to MTConnect data

This session builds on the architectural concepts introduced in Sessions 1 and 2.

---

## 🎯 Learning Objectives

By the end of this session, participants should be able to:

* Understand the structure of an MTConnect Device file
* Define and interpret DataItems
* Model a machine or device using MTConnect standards
* Map raw machine data into standardized MTConnect output
