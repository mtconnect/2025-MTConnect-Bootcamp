# Session 1 — MTConnect Overview

This folder contains materials and resources for **Session 1: MTConnect Overview** from the MTConnect Education Bootcamp 2025.

---

## 📌 Session Description

This session provides a foundational introduction to the **MTConnect standard**, including:

* What MTConnect is and its purpose
* What MTConnect is *not*
* Key concepts and terminology
* How MTConnect delivers value to end users and manufacturers

This session is intended to establish a baseline understanding for all subsequent sessions.

---

## 🎯 Learning Objectives

By the end of this session, participants should be able to:

* Describe the role of MTConnect in manufacturing and IIoT
* Understand the basic architecture and data flow
* Identify common use cases for MTConnect
* Recognize the benefits of standardized machine data
