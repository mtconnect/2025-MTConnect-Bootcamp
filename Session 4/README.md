# Session 4 — Querying MTConnect Agents

This folder contains materials and resources for **Session 4: Querying MTConnect Agents** from the MTConnect Education Bootcamp 2025.

---

## 📌 Session Description

This session provides a hands-on introduction to **querying data from MTConnect Agents**, focusing on how clients access and consume machine data.

Topics covered include:

* How MTConnect Agents expose data
* Standard query interfaces and endpoints
* Types of MTConnect requests (current, sample, probe)
* Working with live data streams

Participants will interact with live or simulated machines to retrieve and analyze MTConnect data.

---

## 🎯 Learning Objectives

By the end of this session, participants should be able to:

* Understand how to query an MTConnect Agent
* Use standard MTConnect request types effectively
* Retrieve real-time and historical machine data
* Interpret MTConnect response documents
